

# Paleta de Cores dos Ícones do Sistema (Phosphor Icons)

No design system atual do app, os ícones do Phosphor seguem três cores semânticas principais baseadas no estado:

Ouro Velho / Destaque Ativo: #c2a675 (usado em abas ativas, botões de ação e títulos principais).

Cinza Chumbo / Neutro Padrão: #6d7872 e #8c938f (usado na navegação inativa, cards fechados e marcadores secundários).

Acentos Semânticos: #ef4444 (Combate / Dano), #38bdf8 (Diplomacia / Magia) e #a855f7 (Pavor).
